# 远程控制系统 - 安卓设备大屏管理

## 项目概述
用于企业环境中远程控制安卓电视等设备，实现帆软大屏内容的集中管理和播放控制。

## 系统架构

### 核心组件

#### 📱 FineReportApp (安卓客户端)
- **技术栈**: Java
- **功能**: 相当于定制化浏览器，用于打开指定网页内容
- **特性**:
  - 强制横屏显示
  - 使用PC User Agent
  - 智能内核选择：
    - 安卓 < 6.0：调用内置XWalk内核
    - 安卓 ≥ 6.0：使用系统WebView
  - 解决WebView兼容性问题
  - 支持远程应用更新

#### ⚙️ FineReportBack (后端服务)
- **技术栈**: Node.js
- **功能**:
  - 接收设备上报信息
  - 下发控制指令
  - 设备状态管理

#### 🖥️ FineReportFront (控制前端)
- **技术栈**: Vue.js
- **功能**: 提供Web控制界面，用于远程管理设备

#### 🗄️ 数据库
- **文件**: SQL 数据库文件
- **用途**: 存储设备信息、版本记录等数据

## 核心功能特性

### 🔄 通信机制
- 基于WebSocket实现实时双向通信
- 确保指令的及时传达和设备状态的实时监控

### 🌐 浏览器兼容性
- **智能内核切换**：
  - 低版本安卓(<6.0)：XWalk内核，提供更好的兼容性
  - 高版本安卓(≥6.0)：系统WebView，性能更优

### 📺 显示优化
- 强制横屏显示，适配大屏场景
- PC UA模拟，确保网页正常显示

### 🔄 应用管理
- 远程更新应用功能
- 处理高版本安装兼容性问题

## 应用场景
适用于企业环境中的数字标牌、信息发布、数据大屏展示等场景，实现集中化、远程化的内容管理。
